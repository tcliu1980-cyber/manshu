課前準備

需要 Pico W、具資料傳輸功能的 Micro-USB 線、電腦、Thonny，以及選配的麵包板、LED、330 Ω 電阻、按鈕。馬達實驗另外需要 DRV8833、空心杯馬達及符合規格的獨立馬達電源。

重要：本講義針對 Pico W 的 MicroPython，不是 Raspberry Pi Zero W 上的 Python 3。兩者不能直接交換 GPIO 程式。
Thonny 操作用途
F5執行目前編輯區的程式

01｜認識 Pico W 與 MicroPython

Pico W 是微控制器，不需要安裝 Raspberry Pi OS。Thonny 在電腦上編輯程式，MicroPython 在 Pico W 上執行。

認識第一行 Python

print("Hello, Pico W!")

逐步解釋：print 是顯示文字的指令；括號 () 放入要顯示的內容；引號代表字串。執行後在 Shell 看到 Hello, Pico W!。

文字與數字

print("3 + 5")
print(3 + 5)

逐步解釋：第一行有引號，顯示 3 + 5；第二行沒有引號，計算得到 8。

02｜Thonny 安裝、連線與上傳

請使用可傳輸資料的 Micro-USB 線。首次安裝韌體：拔掉 USB → 按住 BOOTSEL → 插入 USB → 電腦出現 RPI-RP2 → 複製 Pico W 專用 MicroPython UF2。接著開啟 Thonny，於「執行 → 選擇直譯器」選擇 MicroPython (Raspberry Pi Pico)，並指定連接埠。

第一支可執行程式

print("我的第一支 Pico W 程式")

逐步解釋：在編輯區輸入後按 F5 執行。按 Ctrl+S，選擇 Raspberry Pi Pico 儲存為 hello.py。若儲存為 main.py，Pico W 重新供電時會自動執行。

03｜變數與資料型態

變數就像貼了名字的盒子，用 = 將右邊的資料存到左邊。Python 常見型態：int 整數、float 小數、str 文字、bool 布林值。

變數

speed = 30
name = "風扇船"
running = True
print(name)
print(speed)

逐步解釋：speed 是整數；name 是字串；running 是布林值 True。變數名稱不能以數字開頭。

數學運算

a = 10
b = 3
print(a + b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)

逐步解釋：+ 加、* 乘、/ 除、// 整數除法、% 餘數、** 次方。

04｜判斷式 if / elif / else

條件判斷能讓程式依照情況採取不同動作。注意冒號 : 與縮排（建議 4 個空白）。== 是比較是否相等；= 是指定值。

依速度判斷

speed = 60
if speed >= 80:
    print("高速")
elif speed >= 40:
    print("中速")
else:
    print("低速")

逐步解釋：程式由上而下檢查，符合條件的區塊才執行。這個例子顯示「中速」。

想一想：若 speed = 60，speed >= 80 的結果是？
顯示答案False；60 沒有大於或等於 80。

05｜迴圈 for 與 while

for 適合已知重複次數；while 適合依條件持續重複。無限迴圈執行時可在 Thonny 按停止或 Ctrl+C。

for 重複五次

for i in range(5):
    print(i)

逐步解釋：range(5) 產生 0、1、2、3、4，不包含 5。

while 倒數

count = 3
while count > 0:
    print(count)
    count = count - 1
print("完成")

逐步解釋：每次迴圈都讓 count 減 1，避免無法結束的迴圈。

想一想：range(4) 會產生哪幾個數字？
顯示答案0、1、2、3。

06｜函式與模組

函式把一組動作命名，方便重複使用；import 可以載入別人寫好的功能。

自訂函式

def greet(name):
    print("你好，" + name)

greet("小明")
greet("小華")

逐步解釋：def 用來定義函式；name 是參數；呼叫函式時將資料傳入。

時間模組

from time import sleep
print("開始")
sleep(1)
print("一秒後")

逐步解釋：sleep(1) 暫停約 1 秒，適合 LED 與馬達測試。

07｜GPIO 與板載 LED

GPIO 是可由程式控制的腳位。Pico W GPIO 為 3.3 V 邏輯，不可直接連接馬達，也不可將 5 V 訊號直接送入 GPIO。Pico W 板載 LED 使用 Pin("LED")，與一般 Pico 的寫法不同。

板載 LED 閃爍

from machine import Pin
from time import sleep

led = Pin("LED", Pin.OUT)
while True:
    led.on()
    sleep(0.5)
    led.off()
    sleep(0.5)

逐步解釋：Pin 是腳位物件；Pin.OUT 表示輸出；on() 和 off() 切換 LED。此程式會一直閃爍。

外接 LED：GP15

from machine import Pin
led = Pin(15, Pin.OUT)
led.on()

逐步解釋：外接 LED 必須串聯限流電阻，例如 330 Ω，並確認 LED 極性與 GND 接法。

想一想：Pico W 板載 LED 要寫 Pin(25) 還是 Pin("LED")？
顯示答案使用 Pin("LED")。

08｜讀取按鈕與數位輸入

輸入腳位可以讀取外部按鈕。使用內部上拉電阻時，按鈕接在 GPIO 與 GND 之間：未按下通常為 1，按下為 0。

按鈕控制板載 LED

from machine import Pin
from time import sleep

button = Pin(14, Pin.IN, Pin.PULL_UP)
led = Pin("LED", Pin.OUT)
while True:
    led.value(button.value() == 0)
    sleep(0.02)

逐步解釋：GP14 讀取按鈕；Pin.PULL_UP 啟用上拉。按下時 button.value() 為 0，LED 亮起。

09｜PWM：用占空比調整輸出

PWM 不是直接輸出可調的直流電壓，而是快速切換高低電位。占空比越大，高電位時間比例越高。duty_u16() 範圍 0～65535。

GP15 輸出 PWM

from machine import Pin, PWM
from time import sleep

pwm = PWM(Pin(15))
pwm.freq(1000)
pwm.duty_u16(32768)  # 約 50%
sleep(3)
pwm.duty_u16(0)
pwm.deinit()

逐步解釋：freq(1000) 表示每秒約 1000 個週期。這是控制訊號，不可以直接把馬達接在 GP15 上。

想一想：PWM 的 duty_u16(0) 代表什麼？
顯示答案占空比為 0%，持續低電位。

10｜DRV8833 與空心杯馬達入門

DRV8833 是雙 H 橋有刷直流馬達驅動器，能控制兩顆小型有刷空心杯馬達。注意：您先前提到 DRV8233，實作前請以模組上的晶片印字核對型號及接線圖；以下程式只適用於已確認為 DRV8833 的模組。

單馬達方向與速度（示意接線）

from machine import Pin, PWM
from time import sleep

in1 = PWM(Pin(16))  # GP16 → AIN1
in2 = PWM(Pin(17))  # GP17 → AIN2
in1.freq(1000)
in2.freq(1000)

def motor(speed):
    speed = max(-65535, min(65535, speed))
    if speed > 0:
        in1.duty_u16(speed)
        in2.duty_u16(0)
    elif speed < 0:
        in1.duty_u16(0)
        in2.duty_u16(-speed)
    else:
        in1.duty_u16(0)
        in2.duty_u16(0)

motor(20000)
sleep(2)
motor(0)

逐步解釋：GP16、GP17 連至 AIN1、AIN2；馬達接 AOUT1、AOUT2；馬達電源接 VM、GND，Pico W 與驅動器必須共地。若模組有 nSLEEP，依模組規格使其有效。先用低功率短時間測試，確認電源電壓、啟動電流與驅動器額定值。

11｜Wi-Fi 網頁控制的準備

Pico W 可連上 Wi-Fi，執行簡易 HTTP 伺服器。先學會連線與查詢 IP，下一單元再製作手機網頁按鈕。

連接 Wi-Fi

import network
from time import sleep

wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect("你的WiFi名稱", "你的WiFi密碼")
for i in range(20):
    if wlan.isconnected():
        break
    sleep(1)
if wlan.isconnected():
    print("IP:", wlan.ifconfig()[0])
else:
    print("連線失敗，請檢查設定")

逐步解釋：STA_IF 是連線到現有 Wi-Fi 的模式；isconnected() 判斷是否連線成功。不要把真正的 Wi-Fi 密碼公開在網站或程式分享平台。
