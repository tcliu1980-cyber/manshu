01
WHAT IS AN MCU?

MCU 是一部縮小到晶片裡的控制電腦

MCU 是 Microcontroller Unit，中文稱微控制器。它把運算核心、記憶體及輸入輸出周邊整合在同一顆積體電路中，適合不斷重複「讀取—判斷—控制」的任務。

MCU

微控制器

晶片內已包含 CPU、記憶體、GPIO、Timer 等周邊。通常功耗低、開機快，適合控制裝置。

CPU

運算核心

CPU 是 MCU 裡負責讀取指令、解碼、運算與決策的部分。CPU 是 MCU 的一部分，不等於整顆 MCU。

DEVELOPMENT BOARD

開發板

在 MCU 外加入 USB、穩壓電路、Reset 按鈕、接頭和保護電路，讓我們更容易供電、燒錄與接線。

?
Arduino UNO 是 MCU 嗎？

不是。Arduino UNO 是開發板。UNO R3 的主 MCU 是 ATmega328P；UNO R4 Minima 的主 MCU 是 Renesas RA4M1。

教師提問

為什麼洗衣機通常使用 MCU，而不是桌上型電腦的處理器？

洗衣機的任務固定：讀按鍵、門鎖、水位和溫度，再依流程控制馬達、閥門與蜂鳴器。MCU 成本低、功耗低、開機快，而且可以直接連接這些 I/O。

INSIDE THE CHIP

MCU 內部不是一個房間，而是一座互連的工廠

CPU 不會直接「碰到」每一根接腳。它透過內部匯流排讀寫記憶體與周邊的暫存器；GPIO、Timer、ADC 和通訊控制器則各自完成專門工作。

Bus｜匯流排

晶片內共享的資料道路，通常包含資料、位址與控制訊號。CPU 用位址指定要讀寫哪一個記憶體位置或周邊暫存器。

Register｜暫存器

位於 CPU 或周邊內的小型高速儲存位置。改變其中某些 bit，就能改變 GPIO 方向、啟動 Timer 或送出資料。

Peripheral｜周邊

不是外接模組，而是 MCU 內部的專用硬體功能，例如 ADC、Timer、UART。它們能在 CPU 少量介入下持續工作。

THE 0–1 BRIDGE

bit、byte、二進位與邏輯閘：只學現在需要的部分

bit
最小資料單位，只有 0 或 1。硬體中通常對應兩個可區分的電壓或狀態。

byte
通常由 8 bits 組成，可表達 00000000 到 11111111，也就是十進位 0–255。

Binary／Hex
二進位只用 0、1；十六進位用 0–9、A–F，一個十六進位數字剛好代表 4 bits，方便閱讀暫存器。

Logic Gate
AND、OR、NOT 等邏輯閘是處理 0／1 的電子電路。大量邏輯閘組成 CPU、記憶體與周邊控制器。

03
MEMORY

Flash 保存程式，SRAM 支撐程式運行

「記憶體」不是只有一種。MCU 使用不同種類的記憶體，分別解決斷電保存、快速讀寫與少量設定資料保存等需求。

Flash斷電後保留

非揮發性記憶體。程式編譯後的機器碼通常儲存在這裡。讀取快，但寫入前常需要以區塊擦除，寫入壽命也有限。

SRAM斷電後消失

揮發性記憶體。用來存放正在變化的變數、陣列，以及記錄函式呼叫與返回位置的堆疊（stack）。速度快，但容量通常比 Flash 小。

EEPROM／Data Flash斷電後保留

適合保存校正值、裝置編號或設定。不同 MCU 的實作不同；有些用專用 EEPROM，有些用 Data Flash 或模擬方式。

POWER OFF

拔掉電源後

Flash 內的程式仍在；EEPROM中的設定通常仍在；SRAM裡當次運行的變數消失。再次上電時，程式從重置入口重新開始。

BEGINNER TRAP

Flash 大，不代表變數空間也大

UNO R3 雖有 32 KB Flash，但 SRAM 只有 2 KB。很長的字串或大陣列可能讓 SRAM 用盡，即使程式仍放得進 Flash。

教師提問

程式中的計數器變數，為何重新開機後通常回到初始值？

計數器在執行期間通常位於 SRAM；SRAM 需要持續供電才能保存資料。重新上電後，啟動程式會重新建立變數並賦予初始值。
04
COMPILE & UPLOAD

為什麼程式需要「燒錄」進 MCU？

人寫的 Arduino C/C++ 原始碼不是 CPU 能直接執行的電壓控制序列。它必須先轉換成特定 MCU 認得的機器碼，再寫入非揮發性的程式記憶體。

1 原始碼人可讀的 C/C++
2 編譯轉為目標指令
3 連結合併函式與函式庫
4 HEX／BIN可燒錄的機器碼
5 傳輸USB／UART／SWD／ISP
6 寫入 Flash保存韌體
7 Reset 執行從重置入口開始

原始碼：人看得懂，CPU還看不懂

例如 digitalWrite(13, HIGH)，必須依目標晶片和核心函式庫轉成真正的機器指令。

Firmware｜韌體

寫入嵌入式裝置、控制硬體行為的程式。它不像一般桌面軟體由使用者每次點擊啟動，而常在上電後自動執行。

Bootloader｜開機載入程式

位於 MCU 特定記憶體區的小程式。上電或 Reset 後先檢查是否有新程式要接收；若沒有，就跳到使用者程式。

Programmer／Debugger

燒錄器／除錯器可經由 ISP、SWD 或 JTAG 等專用硬體介面，直接寫入程式、暫停 CPU 或查看暫存器，不一定經過 Bootloader。

!
「燒錄」不是把晶片燒熱

這個名稱來自早期可程式化記憶體的寫入習慣。現代 Flash 是利用電場改變記憶單元的電荷狀態，正常燒錄不應造成可感覺的高溫。

05
CLOCK & RESET

Clock 是全晶片共用的節拍器

Clock 是週期性變化的數位訊號。許多同步電路只在指定邊緣更新狀態，因此 CPU、Timer 和通訊周邊能按照共同節拍前進。

4 MHz
250 ns一個 Clock 週期 T = 1/f
4,000,000每秒週期數

Oscillator｜振盪源

產生規律週期訊號的電路，可來自晶體、陶瓷振盪器、RC振盪器或晶片內部振盪器。Clock system 再分頻、倍頻並送往各模組。

Frequency｜頻率

單位 Hz，表示每秒週期數。16 MHz 等於每秒一千六百萬個週期，但不代表每秒一定執行一千六百萬行 C++。

Reset｜重置

把 CPU 與關鍵周邊帶回已知狀態，並讓程式從重置入口重新開始。Reset 不會等同清除已燒錄的 Flash。

≠
Clock cycle 不一定等於一條程式指令

不同指令可能需要不同週期；快取、Flash等待時間、中斷與編譯結果也會影響實際速度。時脈越高通常也伴隨較高功耗與更嚴格的電源、訊號完整性要求。

06
TIMER / COUNTER

Timer 是會自己數 Clock 的硬體計數器

如果 CPU 忙著用迴圈數數，它很難同時做其他事。Timer 由硬體根據時脈自動遞增，達到指定值時可改變輸出、產生事件或提出中斷請求。

1 CLOCK

時脈來源

來自系統 Clock 或外部脈衝。

2 PRESCALER

預除頻器

先把過快的 Clock 除以 8、64、256 等倍率。

3 COUNTER

計數器

每收到一個計數 Clock，就增加或減少一次。

4 EVENT

事件

溢位或 Compare Match 時，可觸發中斷或改變接腳。

Interrupt｜中斷

周邊發生重要事件時，暫時請 CPU 停下目前流程，先執行一段中斷服務程式，完成後再回去。它避免 CPU 不斷輪詢。

Compare Match｜比較符合

當 Timer 數到預先設定的值，硬體就產生事件。這能建立準確週期、排程取樣，或在不用 CPU 每次介入的情況下產生 PWM。

教師提問

Prescaler 變大，Timer 的「解析度」與「最長計時範圍」如何改變？

Prescaler 變大後，每一個 tick 間隔變長，時間解析度變粗；但計數器較慢到達最大值，因此不溢位的最長計時範圍變長。
07
GENERAL-PURPOSE INPUT / OUTPUT

GPIO 是可由程式設定角色的數位接腳

GPIO 並不是「隨便接都可以」。它內部包含輸入緩衝器、輸出驅動器與模式控制；程式必須先決定接腳是讀取外界，還是主動輸出電位。

VCC / VDD

電源接腳

為晶片或某一電壓域供電。它不是一般 GPIO，不可任意當訊號腳使用。

GND / VSS

參考地

電壓的共同參考點與回流路徑。兩個模組通訊時通常必須共地。

RESET

重置接腳

以指定電位觸發重置。可能需要上拉電阻或依 datasheet 接電容形成上電重置。

GPIO

數位輸入／輸出

輸入模式讀取 HIGH／LOW；輸出模式由驅動器拉高或拉低。

ADC / AIN

類比輸入

將連續電壓量化成數字。輸入不可超過允許範圍，解析度由 ADC 位元數決定。

XTAL / OSC

外部時脈接腳

連接晶體或外部 Clock。周圍電容與走線需依硬體設計建議。

HIGH／LOW

是電壓範圍，不是永遠精確等於 5 V／0 V。datasheet 會用 VIH、VIL、VOH、VOL 定義可接受範圍。

!

Pin Multiplexing｜接腳複用

晶片內部有切換器，把多個周邊功能連到同一實體腳位。設定某功能後，該腳位可能不再受一般 GPIO 暫存器控制。不同 MCU 的可映射方式不同，必須查 pinout 與 alternate-function table。

08
PULSE-WIDTH MODULATION

PWM 用開關時間比例，控制平均效果

PWM 讓接腳快速在 HIGH 與 LOW 之間切換。每一週期中 HIGH 所占比例稱為 Duty Cycle；Timer 通常負責準確產生這個波形。

50%
平均效果 ≈ 50%

Duty Cycle｜占空比

D = tHIGH / T。50% 表示每個週期一半時間為 HIGH。它改變平均能量，不一定改變 PWM 頻率。

Frequency｜頻率

一秒內重複幾個 PWM 週期。太低可能造成 LED 閃爍或馬達噪音；太高則受 Timer 解析度與負載特性限制。

PWM ≠ 真正 DAC

接腳瞬時仍只有 HIGH 或 LOW。若需要平滑電壓，可加入低通濾波器；精密類比輸出則使用 DAC。

SPI 可同時送與收

每個 Clock 邊緣，兩端的 shift register 同時移出與移入一個 bit，因此是全雙工。雙方還必須使用相同的 Clock polarity 與 phase（SPI mode）。

介面主要線路裝置選擇同步方式典型優勢
UARTTX、RX、GND通常點對點無 Clock；約定 baud簡單、適合 GPS 與序列監控
I²CSDA、SCL、GND7-bit／10-bit 位址SCL兩條訊號線共享多個感測器
SPISCK、MOSI、MISO、CS、GND每裝置常有獨立 CSSCK速度快、全雙工、協定簡潔
10
READ THE DATASHEET

看 datasheet，不必從第一頁讀到最後一頁

資料表是晶片設計者提供的規格文件。初學者先學會帶著問題找表格與章節：這根腳可做什麼？電壓能否相容？Timer 有幾位元？通訊功能能映射到哪裡？

STEP 1

先確認型號與封裝

同系列可能有不同腳數與封裝。先找完整料號，再對照正確 pinout。

STEP 2

找 Pin Functions

確認電源、Reset、GPIO、ADC 與 Alternate Functions。不要只看開發板絲印。

STEP 3

查電氣規格

Operating Conditions、DC Characteristics 與 Absolute Maximum Ratings 是三種不同概念。

STEP 4

找周邊章節

Timer、ADC、UART、I²C、SPI 章節會說明功能、限制與設定順序。

STEP 5

查 Clock Tree

周邊頻率可能不是 CPU 頻率。Timer 與通訊速度計算前，先找它實際使用的 Clock。

STEP 6

回到開發板原理圖

MCU 腳位可能已接 LED、USB 或其他元件。開發板 schematic 才能說明板上實際連線。

任務
五分鐘資料表尋寶

分組選 UNO R3 或 UNO R4：找出主 MCU、Clock、Flash、SRAM、GPIO 電壓、UART 腳位、I²C 的 SDA/SCL，以及 SPI 的 SCK/MOSI/MISO/CS。最後由每組說出一項「不能只看 Arduino 腳位編號就知道」的資訊。

11
CHECK & GLOSSARY

能說出「為什麼」，才算真的認識這些接腳

先用下面的檢核表確認學習成果，再利用可搜尋術語表回顧英文縮寫。教師可隨機點名，每題以一句完整因果句回答。

Q1

為何燒錄後拔掉 USB，程式仍能再次執行？

機器碼已寫入非揮發性的 Flash；USB 只是常見的供電與傳輸路徑。重新供電後 MCU Reset，再從 Flash 取指令。
Q2

I²C 為何有 SDA 和 SCL，卻通常沒有 CS？

SDA 傳資料、SCL 提供節拍；Controller 在資料中傳送裝置位址來選擇 Target，因此多個裝置可共享兩條訊號線。
Q3

PWM 50% 為何不是固定輸出一半電壓？

接腳仍快速切換完整 HIGH 與 LOW，只是兩者時間各半；負載或濾波器看到的是平均效果。
Q4

為何 SPI 的 CS 不可和 I²C 位址混為一談？

CS 是一條實體選擇線，Controller 以電位選中 SPI 周邊；I²C 則把位址放在 SDA 傳輸內容中。

專有名詞快速查詢

MCUMicrocontroller Unit；整合 CPU、記憶體與周邊的微控制器。
CPUCentral Processing Unit；取指令、解碼並執行運算的核心。
ALUArithmetic Logic Unit；CPU 內執行加減、比較與位元邏輯運算的電路。
Stack依後進先出方式保存函式呼叫、返回位置與區域資料的 SRAM 區域。
bit最小資料單位，只有 0 或 1 兩種狀態。
byte通常由 8 bits 組成；一個 unsigned byte 可表示 0–255。
Binary以 2 為基底的表示法，只使用數字 0 與 1。
Hexadecimal十六進位；常以 0x 開頭，一個 hex digit 對應 4 bits。
Logic Gate依 AND、OR、NOT 等邏輯規則處理二值訊號的電子電路。
Bus模組間共享的資料、位址與控制訊號通道。
RegisterCPU 或周邊內的小型高速儲存位置；各 bit 常直接控制硬體功能。
PeripheralMCU 內執行特定功能的硬體模組，如 Timer、ADC 或 UART。
Flash斷電後保留，通常存放韌體機器碼。
SRAM高速揮發性記憶體，存放執行中的變數與 stack。
EEPROM適合保存少量、需要斷電保留的設定資料。
Clock週期性節拍訊號，協調 CPU 與同步周邊更新狀態。
Timer / Counter依 Clock 或外部脈衝自動計數的硬體周邊。
Prescaler先降低輸入 Clock 頻率，再送進 Timer。
Interrupt重要事件請 CPU 暫停主流程、先執行服務程式的機制。
GPIOGeneral-Purpose Input/Output；可設定為數位輸入或輸出的接腳。
VCC / VDD晶片的正電源接腳名稱；實際電壓與每個電源域的接法必須查資料表。
GND / VSS電路的共同電位參考與電流回流路徑。
Pull-up / Pull-down以較大電阻把輸入連向 VCC 或 GND，提供未驅動時的穩定預設狀態。
Active-low訊號在 LOW 時代表啟用、按下或成立；名稱上方常以橫線或尾碼 n 表示。
MOSFET可用小控制訊號切換較大負載電流的電晶體，常作為馬達或燈條驅動開關。
Flyback Diode跨接在線圈負載兩端，關閉時為感應電流提供路徑，降低高壓突波。
VIH / VIL輸入保證判為 HIGH 的最低電壓，以及保證判為 LOW 的最高電壓；VOH／VOL 則描述輸出。
PWM以 HIGH 時間比例控制平均效果的脈衝寬度調變。
UART非同步序列通訊；常用 TX、RX 與 GND。
TXTransmit；資料送出端，通常接對方 RX。
RXReceive；資料接收端，通常接對方 TX。
I²C使用 SDA、SCL 與位址，讓多裝置共享匯流排。
SDASerial Data；I²C 的雙向資料線。
SCLSerial Clock；I²C 的時脈線，通常由 Controller 產生。
SPI以 SCK、資料線與 CS 連接高速周邊的同步序列介面。
SCK / SCLKSPI 的 Serial Clock。
CS / SS選中某個 SPI 周邊的實體控制線，常為低電位有效。
MOSI / COPISPI 中 Controller 傳給 Peripheral 的資料線。
MISO / CIPOSPI 中 Peripheral 傳回 Controller 的資料線。
ADCAnalog-to-Digital Converter；把輸入電壓量化成數值。
BootloaderReset 後先運行、可接收新韌體並跳到使用者程式的小程式。
Firmware控制嵌入式硬體行為並儲存在裝置中的程式。
Compiler把高階語言原始碼翻譯成目標處理器指令的工具。
Linker合併程式與函式庫、解析符號並安排最終記憶體位址的工具。
Machine Code依特定 CPU 指令集編碼，可由 CPU 直接取出與執行的位元內容。
HEX / BIN File承載已編譯機器碼的檔案格式；BIN 是原始位元組，Intel HEX 另含位址與檢查資訊。
ISPIn-System Programming；晶片留在電路板上即可使用專用接腳燒錄。
SWDSerial Wire Debug；Arm MCU 常用的雙訊號燒錄與除錯介面。
JTAG標準化的晶片測試與除錯介面，可控制核心並觀察內部狀態。
Baud RateUART 雙方約定的符號傳送速率；常見設定如 9600、115200 baud。
Open-drain輸出只能主動拉 LOW，HIGH 由外部上拉電阻產生，便於多裝置共享線路。
Duty Cycle一個週期中訊號處於 HIGH 的時間比例。
Reset讓 CPU 與關鍵周邊回到已知狀態，程式從重置入口重新開始。
燒錄／Programming把編譯後的機器碼寫入 MCU 程式記憶體。
