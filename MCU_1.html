02
WHAT IS AN MCU?

一顆晶片裡的小型控制中心

MCU 把運算、記憶與輸入輸出周邊整合在一起，專門反覆執行明確的控制任務。

Flash儲存程式
Timer / PWM計時與波形
SRAM暫存變數
CPU讀指令・運算・判斷
GPIO數位輸入／輸出
ADC讀取類比電壓
UART / I²C / SPI與其他裝置通訊
MCU

控制晶片

把 CPU、記憶體、GPIO、計時器與通訊周邊整合在單一晶片，適合即時控制與低功耗裝置。

  • 8-bit：ATmega328P、PIC16F
  • 32-bit：RA4M1、STM32F103、RP2040／RP2350、ESP32-C3／S3、nRF52840
MPU

運算處理器

重視大量運算與複雜軟體，通常需外接 RAM、儲存裝置，並執行 Linux、Windows 等作業系統。

  • Arm：Broadcom BCM2711／BCM2712、NXP i.MX 系列
  • 電腦：Intel Core、AMD Ryzen
BOARD

開發板

把控制晶片、USB、穩壓、時脈、接頭與保護電路放在板上，方便供電、燒錄、接線與測試。

  • 入門：Arduino UNO R3／R4、micro:bit V2
  • 延伸：ESP32-DevKitC、STM32 Nucleo、Raspberry Pi Pico／Pico 2
A SHORT HISTORY

MCU 的發展：從「把電腦縮小」到「讓萬物可控制」

重點不是背年份，而是觀察整合程度的改變：早期需要許多外接晶片；後來 CPU、記憶體與周邊逐步進入同一顆晶片，現在甚至連無線通訊與安全功能也能整合。

1971

微處理器起點

Intel 4004 代表單晶片 CPU 的早期里程碑，但它本身仍不是完整 MCU。

1970s

單晶片控制器

TI TMS1000、Intel MCS-48 等把運算、記憶與 I/O 整合，家電開始大量使用電子控制。

1980

8051 世代

Intel 8051 架構成為經典，衍生型號長期出現在工業控制與教學。

1990s

PIC 與 AVR 普及

Flash 程式記憶體與更容易使用的開發工具，讓控制器更適合教學與快速設計。

2000s

32-bit 與 Arduino

Arm Cortex-M 擴大 32-bit MCU 生態；Arduino 以開發板與簡化軟體降低入門門檻。

現在

連網、低功耗、AI

MCU 可整合 Wi-Fi、Bluetooth、安全加密與輕量 AI，進入穿戴、IoT、車用與太空裝置。

COMMON MCU FAMILIES

現在常見的 MCU 型號與用途

型號很多，不必全部背誦。先看位元數、運算核心、電壓、記憶體、通訊、ADC／PWM 與功耗，再依任務選擇。

CLASSIC 8-BIT

ATmega328P

Arduino UNO R3 的經典 8-bit AVR MCU，資源不大但結構清楚、教學資料多。

常見用途：基礎程式、按鍵、LED、小型感測與簡單馬達控制。
ARM CORTEX-M4

Renesas RA4M1

Arduino UNO R4 的 32-bit MCU，具較高效能、ADC、DAC、RTC 與 CAN 等周邊。

常見用途：進階 Arduino、量測、控制、音訊輸出與 CAN 裝置。
ARM CORTEX-M

STM32 系列

從入門到高效能型號完整；STM32F103 是常見教學型號之一。

常見用途：工業控制、馬達、儀器、機器人、無人機與嵌入式產品。
WIRELESS / RISC-V

ESP32-C3／S3

將 MCU 與 Wi-Fi、Bluetooth LE 整合；C3 採 RISC-V，S3 適合較高效能與向量運算。

常見用途：IoT、網頁控制、無線感測、智慧家庭與邊緣 AI。
DUAL-CORE

RP2040／RP2350

Raspberry Pi 自有 MCU；分別用於 Pico 與 Pico 2，特色包含雙核心與可程式化 I/O。

常見用途：教學、訊號時序、資料擷取、機器人與自製介面。
LOW-POWER BLE

nRF52840

以低功耗 Bluetooth LE 與豐富無線協定能力著名。

常見用途：穿戴裝置、藍牙感測器、低功耗遙控與無線網狀系統。
點名提問

Arduino UNO 是 MCU 嗎？

教師參考：不是。Arduino UNO 是開發板；真正的 MCU 是板上的晶片。UNO R3 使用 ATmega328P，UNO R4 使用 Renesas RA4M1。

點名提問

洗衣機為什麼適合使用 MCU？

教師參考：它要反覆讀取門、水位與按鍵，再依流程控制進水閥、馬達與蜂鳴器；任務明確而且需要即時反應。

READ THE SILKSCREEN

Arduino 腳位上的字代表什麼？

同一支 pin 可能同時具有多種功能。先看板上的印字，再查該版本的 pinout；UNO R3 與 UNO R4 的可用腳位與能力不完全相同。

DIGITAL

數位輸入／輸出

只辨認兩種邏輯狀態：LOW 與 HIGH。可讀按鍵，也可控制 LED、繼電器或其他數位裝置。

在 UNO 上常以 D0、D1……或 0、1……標示。
ANALOG IN / INPUT

類比輸入

讀取一段範圍內的電壓，而不是只有 0 或 1；MCU 內的 ADC 會把電壓轉成數字。

Arduino 板上常印 ANALOG IN，腳位通常標示為 A0、A1……。
TX

Transmit 傳送

UART 串列通訊的傳送腳，MCU 從這裡把一連串 0 與 1 送給其他裝置。

接線原則：本板 TX 通常接對方 RX，並共用 GND。
RX

Receive 接收

UART 串列通訊的接收腳，MCU 從這裡接收其他裝置送來的資料。

UNO R3 的 D0 是 RX、D1 是 TX；使用時要留意 USB 串列通訊衝突。
PWM / ～

脈寬調變

以很快的 HIGH／LOW 切換改變平均功率，常用於調整 LED 亮度或直流馬達速度。

PWM 是數位脈波，不是連續類比電壓；有「～」的腳才支援對應的 PWM 功能。
點名提問

請指出：哪一顆才是真正執行程式的 MCU？

教師參考：板上中央或靠中央、印有晶片型號的黑色積體電路。不同 UNO 版本位置與封裝可能不同，應以板上型號與官方 pinout 確認。

點名提問

為什麼 pin 腳要分成不同區域？

教師參考：功能不同：數位輸入輸出、類比輸入、電源、GND，以及 UART、I²C、SPI 等通訊腳位。

FOLLOW THE SIGNAL

訊號如何一路走進 MCU，再變成動作？

看到一個系統時，可以沿著下列順序追問。類比訊號需要先經 ADC 數位化；按鍵等數位訊號則由 GPIO 直接判斷 HIGH 或 LOW。

01 / SENSOR

感測器或按鍵

把光、溫度、壓力或人的動作轉成電訊號。

→
02 / SIGNAL

類比或數位訊號

類比：連續變化的電壓。數位：LOW／HIGH 兩種狀態。

→
03 / INTERFACE

ADC 或數位 GPIO

ADC 將電壓轉成數值；GPIO 直接讀取邏輯狀態。

→
04 / MCU + OUTPUT

判斷並控制

程式比較條件，再控制 LED、蜂鳴器、馬達或傳送資料。

DIGITAL INPUT

數位輸入：只問「0 還是 1？」

例如按鍵未按是 LOW、按下是 HIGH。實際判定使用電壓範圍，不是要求剛好等於 0 V 或 5 V；門檻值依 MCU 與供電電壓而定。

LOW / 0HIGH / 1
ANALOG INPUT + ADC

類比輸入：先量電壓，再變成數字

ADC 是 Analog-to-Digital Converter。以常見 10-bit ADC 為例，可把輸入範圍分成 1024 階，讀值通常為 0–1023；解析度與參考電壓會依開發板設定而不同。

低電壓 → 0高電壓 → 1023
DEFAULT STATE

為什麼需要上拉與下拉電阻？

輸入腳阻抗很高。若按鍵放開後沒有任何電路決定電位，腳位會「浮動」，容易受手、導線與環境雜訊影響。上拉或下拉電阻提供穩定的預設狀態，同時在按鍵動作時限制電流。

PULL-UP

上拉：預設 HIGH

電阻把輸入腳輕輕拉向 VCC；按鍵接地時，按下會讀到 LOW。許多 MCU 內建可由程式啟用的上拉電阻。

VCC
10 kΩ→ PIN ←按鍵
→ GND
PULL-DOWN

下拉：預設 LOW

電阻把輸入腳輕輕拉向 GND；按鍵接 VCC 時，按下會讀到 HIGH。電阻值常見約 4.7–10 kΩ，但仍應依電路需求選擇。

點名提問

為什麼 LED 一定要串聯限流電阻？

教師參考：LED 導通後電流可能快速增加；串聯電阻限制電流，避免損壞 LED 或開發板腳位。

點名提問

按鍵未按下時，為什麼輸入腳不能懸空？

教師參考：懸空輸入沒有明確的 HIGH 或 LOW，容易受雜訊影響而亂跳；上拉或下拉電阻能提供穩定的預設電位。

VERBAL CHECK

最後十分鐘：全班口頭檢核

隨機點名，每題只需一句話；答得不完整時，再請另一位同學補充。

01

微控制器與開發板有什麼不同？

參考答案：MCU 是執行程式的控制晶片；開發板則把 MCU、USB、穩壓、時脈與接頭等電路組合起來，方便供電、燒錄與接線。

02

請指出 Arduino 板上的 MCU、LED 與 pin 腳。

參考答案：MCU 是印有型號的主要黑色晶片；LED 常在板上標示 ON、L、TX、RX；pin 腳沿板邊排列，分成 DIGITAL、ANALOG INPUT、POWER 與通訊等區域。實際位置應依板子版本確認。

03

GPIO 可以扮演哪兩種基本角色？

參考答案：可設定為輸入，讀取外部 LOW／HIGH；也可設定為輸出，送出 LOW／HIGH 控制外部裝置。

04

DIGITAL 與 ANALOG INPUT 的差別是什麼？

參考答案：數位輸入只判斷 LOW 或 HIGH；類比輸入可讀取一段範圍內連續變化的電壓，再由 ADC 轉成數字。

05

ADC 做了什麼工作？

參考答案：ADC 把類比電壓轉換成 MCU 可以運算的數值。例如 10-bit ADC 通常把量測範圍分成 1024 階，得到 0–1023 的讀值。

06

TX、RX 與 PWM 分別代表什麼？

參考答案：TX 是串列資料傳送，RX 是串列資料接收；PWM 是以快速 HIGH／LOW 脈波調整平均功率，常用於 LED 亮度或馬達速度，但不等於真正的連續類比輸出。

07

什麼是浮動輸入？上拉或下拉電阻如何改善？

參考答案：浮動輸入沒有確定電位，讀值會受雜訊影響。上拉電阻讓預設值為 HIGH；下拉電阻讓預設值為 LOW。

08

用輸入—處理—輸出描述一個生活裝置。

參考答案：例如自動燈：光感測器與人體感測器是輸入；MCU 判斷「環境暗而且有人」是處理；點亮燈是輸出。
