01 / LEARNING GOAL

這堂課最後能做出什麼？

上傳 main.py 到 Pico W 後，它會開出自己的 Wi-Fi。手機先連入這個無線網路，再開啟它提供的網頁，就能控制兩顆 3.7 V 有刷空心杯風扇馬達。控制網頁是由 Pico W 自己提供，不必購買網址、安裝手機 App 或連上網際網路。

左風扇拉桿往上增加速度，往下降低速度。
0％＝停止；100％＝本課設定的最大控制輸出。
右風扇拉桿獨立調速，和左邊不必相同。兩側速度不同可控制船偏轉方向。

⚠️ 風扇安全！

嚴禁以手指、衣物、頭髮或任何物品阻礙風扇旋轉！馬達堵轉可能產生高電流，導致導線、驅動器或電池過熱，甚至引發火災。
第一次測試請拆下螺旋槳，並由教師檢查。
02 / HOW WI-FI WORKS

Wi-Fi 究竟如何讓手機控制馬達？

一般情況下手機會連到家用路由器；這次我們讓 Pico W 變成 AP（Access Point，無線基地台）。手機直接連到 Pico W，Pico W 同時充當簡單的 HTTP 網頁伺服器。手機操作拉桿會傳送數字命令，由 Pico W 轉成 PWM 控制 DRV8833。

AP（基地台模式）Pico W 主動建立 fan00，手機加入它。不使用家用 Wi-Fi。
HTTP（網頁通訊）手機瀏覽器向 Pico W 發送請求，例如 /api/set?l=30&r=60，意即左 30、右 60。

手機顯示「此 Wi-Fi 無法連上網際網路」是正常的，請選擇保持連線，並在網址列輸入 Pico W 的本機位址（常見為 http://192.168.4.1/，實際以 Thonny 顯示為準）。

03 / WI-FI CREDENTIALS

設定自己的船名與 Wi-Fi 密碼

🚨 每一組一定要修改 SSID！

範例名稱是 fan00。正式上課時請依組別改成 fan01、fan02、fan03……。如果每艘船都叫 fan00，手機可能連到別組的船，導致操作到錯誤的風扇船！
SSID = "fan00"
PASSWORD = "88888888"
SSID 是什麼？SSID 是手機 Wi-Fi 清單看得到的名稱。字母大小寫不同就算不同名稱，建議僅使用英文字母、數字、底線、連字號。
密碼是什麼？本課示範 88888888。這個密碼很容易被猜到，正式競賽建議各組改成長度至少 8 位的不同密碼，不要公開在船身上。

我們在程式中使用 WPA2-PSK（security=3），Wi-Fi 加密與 HTTP 控制是兩回事：加入 Wi-Fi 的使用者仍可操作控制頁。因此課堂示範應限制在受監督的環境中。

04 / WIRING

使用您手上的 HW-627／DRV8833 腳位

以下照片是您先前提供的真實模組。採照片朝向：左邊依序是 IN4、IN3、GND、VCC、IN2、IN1；右側是 EEP、OUT1、OUT2、OUT3、OUT4、ULT。

Pico W / 電源DRV8833 模組說明
GP14（實體 19 腳）IN1左風扇 PWM 控制
GP15（實體 20 腳）IN2左風扇反向輸入，維持 LOW
GP16（實體 21 腳）IN3右風扇 PWM 控制
GP17（實體 22 腳）IN4右風扇反向輸入，維持 LOW
左馬達兩條線OUT1、OUT2接左側 3.7 V 空心杯馬達
右馬達兩條線OUT3、OUT4接右側 3.7 V 空心杯馬達
3.7 V 馬達穩壓供電 +VCC電源需承受兩顆馬達的啟動電流
共同 GNDGND必須與 Pico W 的 GND 共地
EEP／J2模組睡眠／啟用請依上一單元確認 J2 設定；ULT 留作故障輸出

18650 供電方式

沿用上一單元的 1S 18650 電池供電教學：電池正極透過開關接 Pico W 的 Pin 39 VSYS，電池負極接 Pin 38 GND。馬達端建議由合適的3.7 V 升降壓穩壓模組供電到 DRV8833 的 VCC，所有地端必須共地。18650 充滿約 4.2 V，不能僅靠 PWM 將峰值電壓變成穩定的 3.7 V。

USB 與電池：若使用的是課程入門直連接法、沒有規劃正確雙電源隔離，請勿同時接上 USB 與 18650。更改程式時先關閉馬達並斷開電池，使用 USB 上傳；測試電池供電時拔除 USB。

# ============================================================
# ★ 每艘船一定要改成不同 SSID！例如 fan01、fan02、fan03。
# ★ 密碼至少 8 個字元。88888888 只適合教學示範。

# 第一次測試將 PWM 輸出上限限制為 70%。
# 注意：PWM 上限不等於穩壓，不可取代 3.7V 穩壓器。
MAX_PWM_PERCENT = 70

# 超過此時間（毫秒）收不到控制指令，就自動停止兩顆馬達。
CONTROL_TIMEOUT_MS = 1100
PWM_FREQUENCY = 1000

# Pico GP14 -> DRV8833 IN1；GP15 -> IN2
# Pico GP16 -> DRV8833 IN3；GP17 -> IN4
left_pwm = PWM(Pin(14))
left_direction = Pin(15, Pin.OUT, value=0)
right_pwm = PWM(Pin(16))
right_direction = Pin(17, Pin.OUT, value=0)
left_pwm.freq(PWM_FREQUENCY)
right_pwm.freq(PWM_FREQUENCY)
left_pwm.duty_u16(0)
right_pwm.duty_u16(0)

current_left = 0
current_right = 0
last_command_ms = time.ticks_ms()


def set_motors(left, right):
    """接收 0~100 的控制百分比；只允許正向推進。"""
    global current_left, current_right
    left = max(0, min(100, int(left)))
    right = max(0, min(100, int(right)))
    # 先固定 H 橋另一個方向輸入為 LOW。
    left_direction.value(0)
    right_direction.value(0)
    # 兩根拉桿的 100% 對應 MAX_PWM_PERCENT 的占空比。
    scale = 65535 * MAX_PWM_PERCENT // 100
    left_pwm.duty_u16(left * scale // 100)
    right_pwm.duty_u16(right * scale // 100)
    current_left, current_right = left, right


def stop_motors():
    set_motors(0, 0)

def configure_ap():
    """建立有密碼的無線基地台；同時兼容新舊命名方式。"""
    if len(PASSWORD) < 8:
        raise ValueError("Wi-Fi 密碼至少 8 個字元")
    try:
        ap = network.WLAN(network.WLAN.IF_AP)  # 新版 MicroPython
    except AttributeError:
        ap = network.WLAN(network.AP_IF)         # 舊版 MicroPython
    ap.active(False)
    try:
        # 新版常用 ssid / key；3 表示 WPA2-PSK。
        ap.config(ssid=SSID, key=PASSWORD, security=3)
    except (ValueError, TypeError):
        # 早期韌體使用 essid / password。
        ap.config(essid=SSID, password=PASSWORD, security=3)
    ap.active(True)
    for _ in range(40):
        if ap.active():
            break
        time.sleep_ms(100)
    if not ap.active():
        raise RuntimeError("無法啟動 Pico W 無線基地台")
    return ap


def reply(client, status, data, content_type="text/plain; charset=utf-8"):
    """送出 HTTP 回應；資料先轉為 UTF-8 位元組。"""
    if isinstance(data, str):
        data = data.encode("utf-8")
    head = ("HTTP/1.1 " + status + "\r\n"
            + "Content-Type: " + content_type + "\r\n"
            + "Content-Length: " + str(len(data)) + "\r\n"
            + "Cache-Control: no-store\r\nConnection: close\r\n\r\n")
    client.write(head.encode("utf-8"))
    for i in range(0, len(data), 512):
        client.write(data[i:i+512])


def parse_percent(text):
    """只接受 0 至 100 的純數字，避免無效命令誤動馬達。"""
    if not text or not text.isdigit():
        raise ValueError("invalid percent")
    n = int(text)
    if n > 100:
        raise ValueError("percent exceeds 100")
    return n


def handle(client, page_bytes):
    global last_command_ms
    client.settimeout(0.45)
    raw = client.recv(1024)
    if not raw:
        return
    line = raw.split(b"\r\n", 1)[0].decode("ascii", "ignore")
    fields = line.split(" ")
    if len(fields) < 2 or fields[0] != "GET":
        reply(client, "405 Method Not Allowed", "Only GET supported")
        return
    path = fields[1]
    if path == "/" or path == "/index.html":
        reply(client, "200 OK", page_bytes, "text/html; charset=utf-8")
    elif path.startswith("/api/set?"):
        try:
            params = {}
            for pair in path.split("?", 1)[1].split("&"):
                k, v = pair.split("=", 1)
                params[k] = v
            l = parse_percent(params["l"])
            r = parse_percent(params["r"])
        except (ValueError, KeyError):
            stop_motors()
            reply(client, "400 Bad Request", "速度必須是 0～100")
            return
        set_motors(l, r)
        last_command_ms = time.ticks_ms()
        reply(client, "200 OK", "OK")
    elif path == "/api/stop":
        stop_motors()
        last_command_ms = time.ticks_ms()
        reply(client, "200 OK", "STOP")
    elif path == "/favicon.ico":
        reply(client, "204 No Content", b"")
    else:
        reply(client, "404 Not Found", "Not found")


def main():
    global last_command_ms
    stop_motors()  # 開機先停止，避免突然轉動。
    ap = configure_ap()
    ip = ap.ifconfig()[0]
    page = CONTROL_PAGE.replace("__SSID__", SSID).encode("utf-8")
    print("Wi-Fi 名稱:", SSID)
    print("手機連上 Wi-Fi 後，輸入 http://%s/" % ip)
    server = socket.socket()
    try:
        server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        server.bind(("0.0.0.0", 80))
        server.listen(2)
        server.settimeout(0.15)
        last_command_ms = time.ticks_ms()
        print("已啟動 HTTP 伺服器；等待手機連線...")
        while True:
            # 重要：即使手機關閉網頁，也會因為逾時而停轉。
            if time.ticks_diff(time.ticks_ms(), last_command_ms) > CONTROL_TIMEOUT_MS:
                if current_left or current_right:
                    stop_motors()
                    print("逾時：兩顆馬達已自動停止")
            client = None
            try:
                client, address = server.accept()
                handle(client, page)
            except OSError as e:
                # socket.timeout 往往是 OSError；屬於輪詢的正常情況。
                pass
            except Exception as e:
                stop_motors()
                print("請求錯誤：", e)
            finally:
                if client is not None:
                    client.close()
    finally:
        stop_motors()
        server.close()
        ap.active(False)


if __name__ == "__main__":
    try:
        main()
    finally:
        stop_motors()
07 / THONNY WORKFLOW

一步一步把程式上傳到 Pico W

1
拆下螺旋槳，關閉電池

先保護雙手與螺旋槳；先不要讓外接 18650 與 USB 同時供電。

2
以 USB 接 Pico W 到電腦

開啟 Thonny，選擇 MicroPython (Raspberry Pi Pico) 直譯器。確認 Shell 能看到 >>>。

3
打開主程式

Thonny →「檔案」→「開啟」，選擇下載的 main.py，或貼上本頁的完整程式。

4
一定要修改 SSID

把 SSID = "fan00" 改成自己的組別，例如 SSID = "fan07"。如需變更密碼，修改 PASSWORD。

5
儲存至 Raspberry Pi Pico

按 Ctrl+S，選「Raspberry Pi Pico」，檔名必須是 main.py。按 F5 測試；亦可在重新供電後自動執行。

6
查看 Pico W 在 Shell 印出的網址

通常為 http://192.168.4.1/；不要假設所有韌體都一樣，實際看 Shell 顯示的 IP。

7
手機連線

手機設定 → Wi-Fi → 選擇自己的 fan07（或測試用 fan00），輸入 88888888。提示沒有網際網路時選擇維持此 Wi-Fi。

8
輸入網址，操作兩根拉桿

用手機瀏覽器（Chrome、Safari）輸入 http://192.168.4.1/；不需要輸入 HTTPS。先各別試 10%～20%，確認正確的左右馬達再逐步提高。

9
進行失聯測試

在安全固定、無螺旋槳的情況下低速運轉，關閉手機 Wi-Fi 或離開控制頁，觀察是否約 1.1 秒後停止；教師應確認後才進行實船測試。

PASSWORD = "88888888"
# 全班每一艘船改為 fan01、fan02、fan03 ...

SSID 是基地台對外顯示的名稱，PASSWORD 是加入該 Wi-Fi 的密碼。請每一組都改成不同名稱，否則手機可能連到別組的船。使用者的密碼至少 8 字元；88888888 是範例，無法抵擋同場其他人猜測。

02｜設定無線基地台（AP）

ap = network.WLAN(network.WLAN.IF_AP)
ap.config(ssid=SSID, key=PASSWORD, security=3)
ap.active(True)
print(ap.ifconfig()[0])

network.WLAN 管理無線網路；IF_AP 表示基地台模式。security=3 是常用的 WPA2-PSK。設定完成才啟用 active(True)；請以完整 main.py 的相容寫法為準，因不同 MicroPython 版本的參數名稱可能是 ssid/key 或 essid/password。

03｜控制 GPIO 與 PWM

left_pwm = PWM(Pin(14))
left_direction = Pin(15, Pin.OUT, value=0)
right_pwm = PWM(Pin(16))
right_direction = Pin(17, Pin.OUT, value=0)
left_pwm.freq(1000)
right_pwm.freq(1000)

GP14、GP16 是 PWM 輸出；GP15、GP17 維持低電位，讓 H 橋只向設定方向驅動。freq(1000) 代表每秒 1000 個 PWM 週期。實際風扇旋轉方向需透過現場短時間測試核對。

04｜如何把 0～100 轉成占空比？

scale = 65535 * MAX_PWM_PERCENT // 100
left_pwm.duty_u16(left * scale // 100)
right_pwm.duty_u16(right * scale // 100)

duty_u16() 接受 0 至 65535 的值。// 是整數除法；例如 MAX_PWM_PERCENT=70 時，拉桿 100% 對應約 70% 的 PWM 占空比，不等於馬達轉速為 70% 或電壓被穩壓到 70%。

05｜手機如何把速度傳給 Pico？

// 手機瀏覽器中的 JavaScript
fetch('/api/set?l=30&r=60')

手機用 HTTP 傳送 GET 請求，例如左邊 30、右邊 60。Pico W 的 handle() 解析 l 和 r，再呼叫 set_motors(30, 60)。兩顆轉速不同，船就能差速轉向。

06｜如何做到失聯自動停轉？

if time.ticks_diff(time.ticks_ms(), last_command_ms) > 1100:
    stop_motors()

手機約每 300 毫秒送一次狀態，Pico W 每次收到有效控制命令就更新時間。若超過 1100 毫秒仍收不到，停止兩顆馬達。這是軟體層的安全輔助，不能取代實體電源開關，亦不能保證任何硬體故障都會停機。

重要語法對照

指令 / 符號意義

import socket建立接收 HTTP 請求的伺服器
def ...:定義可以重複呼叫的函式；冒號後必須縮排
try ... except避免程式碰到部分預期錯誤時直接失控

09 / SAFETY

為什麼無線控制一定要有安全機制？

① 開機立即停止在任何 Wi-Fi 設定前就將兩顆馬達 PWM 設為 0，避免上電後突然啟動。
② 緊急停止手機上的紅色按鈕會把左右拉桿歸零，並向 Pico W 發送停止要求。
③ 失聯自動停轉超過約 1.1 秒沒收到有效指令就令 PWM 歸零；當手機關閉、離線或收不到訊號時能降低持續運轉風險。
④ 初學輸出上限設定 MAX_PWM_PERCENT=70；學生滑桿 100% 只對應 70% 占空比。安全上限須由教師依電源與馬達實測調整。

⚠️ 安全機制不是硬體保護的替代品

1S 18650 即使有內建保護，仍可能因短路、導線不良或馬達堵轉而發熱。發現電池、馬達、DRV8833 或導線異常發燙，應立即停用；若電池已高溫、冒煙、膨脹，請勿徒手拔線，應遠離並通知教師處理。請保留實體電源開關。

此外，70% PWM 占空比不等同穩定的 3.7 V，仍須依馬達額定電壓及啟動／堵轉電流選擇合適供電。
通電前安全檢核： 電源極性正確、共地正確、線材已固定、螺旋槳已拆下、Wi-Fi SSID 已更改、控制網頁停止鍵可用、失聯停轉已測試、教師已複核。
10 / TROUBLESHOOTING

常見問題與故障排除

手機找不到 fan00 或自己的 fan07？

檢查 Pico W 是否正在執行 main.py、韌體是否支援 Pico W Wi-Fi、Thonny Shell 是否有錯誤。重新供電時先把風扇停止，並確認程式有印出 Wi-Fi 名稱與 IP。

手機顯示「無法連接網際網路」？

這是預期現象：Pico W 只是本地基地台，沒有提供網際網路。手機請選「繼續使用此 Wi-Fi」，必要時暫時關閉自動切換行動數據。

手機有連上，但網頁開不起來？

網址需用 http://，不是 https://。IP 地址請以 Thonny 顯示為準。若網頁仍無法開啟，檢查 main.py 是否卡在錯誤訊息或意外停止。

頁面能操作，但馬達完全不轉？

先斷電檢查電池、3.7 V 馬達穩壓器、DRV8833 VCC/GND、共地、GP14～GP17 的接線與模組 EEP/J2 啟用狀態。請拆下螺旋槳並使用低速測試，不要持續提高 PWM 逼馬達轉動。

上推左滑桿，卻是右馬達轉？

核對 OUT1/OUT2 應接左馬達、OUT3/OUT4 應接右馬達。接線前一律先切斷電源。

Wi-Fi 名稱相同，手機可能抓錯船？

可能。請將每艘船設定為唯一的 SSID，例如 fan01、fan02。現場若已經連錯船，請先停止並斷開該連線，確認正確名稱後再測試。

改密碼後無法連線？

先確認密碼至少 8 字元、名稱與密碼無全形空格。若 MicroPython 韌體較舊導致基地台設定失敗，請更新 Pico W 專用韌體。課堂上必須確認手機顯示有鎖頭、確實需要密碼才能加入。

停止按鈕已按，為何過一瞬間才停？

HTTP 指令需要通訊時間；若已離線，停止指令可能送不到。這時 Pico W 會以逾時機制停轉，但它不是硬體級緊急斷電。真正的危險情況要使用實體電源開關。
