# 2026 無人定翼機三日工作坊招生網站

這是一組可直接上傳的靜態網站草案，使用 HTML/CSS/JavaScript 製作，不依賴外部框架或雲端字型。

## 檔案

- `PlaneIndex.html`：招生首頁
- `curriculum.html`：課程內容
- `donation.html`：捐款與抵稅說明
- `register.html`：報名方式／示意表單
- `assets/`：CSS、JavaScript、SVG 藍圖圖像、示意 QR code

## 上線前待替換

1. 將 `assets/fake-qr.svg` 替換為正式報名、繳費或捐款 QR code。
2. 補上正式地點、聯絡電話、Email、報名表連結。
3. 捐款頁面之抵稅文案，請由學校主計、出納或秘書室確認。
4. 報名頁目前是前端示意表單，不會真的送出資料；正式版可改接 Google 表單或校方報名系統。
