認識 Raspberry Pi Pico W

從認識微控制器、安裝 Thonny、燒錄 MicroPython，到撰寫第一支程式、控制 LED 與 PWM。完成本單元，你就能讓 Pico W 獨立執行自己寫的程式。

知道 Pico W 與一般電腦有何不同，認識 GPIO、USB 與 Wi-Fi。

建立環境

安裝 Thonny IDE 與 MicroPython 韌體，連接開發板。

撰寫程式

學會 print、變數、迴圈、GPIO 與 PWM。

上傳與執行

01｜什麼是 Pico W？

Raspberry Pi Pico W 是一塊微控制器開發板。它不像桌上型電腦需要作業系統與螢幕，而是適合持續執行特定任務，例如讀取感測器、控制燈光或馬達。它還有 Wi-Fi，後續可讓手機透過網頁遙控風扇船。

硬體規格
主晶片RP2040，雙核心 Cortex-M0+，最高 133 MHz
記憶體264 KB SRAM、2 MB Flash
可用 GPIO26 個多功能 GPIO（部分支援 ADC）
通訊2.4 GHz Wi-Fi、Bluetooth（視韌體支援）
GPIO 邏輯3.3 V，不可直接接入 5 V 邏輯訊號
程式語言MicroPython 或 C/C++；本課程採用 MicroPython

📌 開啟 Pico W 官方腳位圖（PDF）

注意：Pico W 的 GPIO 只能提供有限電流，不能直接驅動空心杯馬達。後續會使用 DRV8833 雙 H 橋馬達驅動器。

02｜準備材料與開發軟體

需要：Pico W × 1、可傳輸資料的 Micro-USB 線 × 1、Windows/macOS/Linux 電腦 × 1。第一堂課不需要接馬達。

IDE 是什麼？ IDE（整合開發環境）就是寫程式、執行程式與檢查錯誤的工具。本課程使用 Thonny IDE。其中「編輯器」負責寫完整程式，「Shell」可直接輸入一行指令測試。

步驟 1｜安裝 Thonny

到 thonny.org 下載並安裝，開啟後找到程式編輯區、下方 Shell 與上方綠色執行按鈕。

步驟 2｜下載 Pico W 專用 MicroPython

前往 Pico W 韌體下載頁，下載副檔名為 .uf2 的穩定版本。注意不能下載成 Pico（無 W）或 Pico 2 W 的韌體。

步驟 3｜進入 BOOTSEL 模式

拔掉 USB，按住板上的 BOOTSEL 按鈕不放，再插入 USB。放開按鈕，電腦應出現 RPI-RP2 磁碟。

步驟 4｜燒錄韌體

把下載的 .uf2 檔案複製到 RPI-RP2。磁碟自動消失、Pico W 重新啟動，代表韌體已送入開發板。

步驟 5｜設定 Thonny 直譯器

在 Thonny 選「執行 → 選擇直譯器」，設定為 MicroPython (Raspberry Pi Pico)，選擇對應 USB/序列埠（或先選自動偵測）。下方 Shell 出現 >>> 即可開始。
若找不到 Pico W：先檢查 USB 線是否只能充電、確認已燒錄 Pico W 專用韌體，再重新選擇 Thonny 的連接埠。

03｜第一支程式：Hello World

在 Thonny 下方 Shell 的 >>> 後輸入：

print("Hello, Pico W!")
print(3 + 5)

預期顯示 Hello, Pico W! 和 8。這表示 Pico W 已經能執行 Python 指令。

試著修改成 print("我的第一艘風扇船")，觀察 Shell 的結果。

04｜讓板載 LED 閃爍

在上方編輯器輸入下列程式，按 F5（或綠色執行按鈕）執行：

from machine import Pin
from time import sleep

led = Pin("LED", Pin.OUT)

while True:
    led.value(1)  # 亮燈
    sleep(1)
    led.value(0)  # 熄燈
    sleep(1)
程式碼作用
Pin("LED", Pin.OUT)設定 Pico W 板載 LED 為輸出
while True:持續重複縮排的程式
led.value(1)亮燈
led.value(0)熄燈
sleep(1)暫停 1 秒
LED 模擬器

按下按鈕，模擬程式的亮燈／熄燈。

🧪 小挑戰：把兩個 sleep(1) 改成 sleep(0.2)，觀察 LED 閃爍速度的變化。

Pico W 板載 LED 應使用 Pin("LED")，不要把一般 Pico 的 GP25 範例直接套用。

05｜儲存與上傳程式：main.py

執行程式不等於已經儲存在 Pico W 上。要讓 Pico W 拔掉電腦後仍可開機自動執行：

  1. 先在 Thonny 按 Stop 停止執行中的程式。
  2. 按 Ctrl+S（macOS 可用 Command+S）儲存。
  3. 選擇 Raspberry Pi Pico，不是 This computer。
  4. 輸入檔名 main.py 並確認儲存。
  5. 拔除 USB 後重新接上供電，觀察 LED 是否自動閃爍。

重要差別：test.py 可以手動執行；Pico W 上的 main.py 則會在 MicroPython 啟動時自動執行。

06｜初識 GPIO 與 PWM

GPIO 是可由程式控制的輸入／輸出腳位。數位輸出可以切換高電位（約 3.3 V）與低電位（0 V）。PWM 則是快速切換高低電位，利用「占空比」調整平均輸出效果，後續將用來控制馬達速度。

占空比 0%：始終低電位；50%：高低電位各佔一半；100%：始終高電位。

下列程式會在 GP15 產生 1000 Hz 的 PWM 訊號，第一堂課不需要接馬達：

from machine import Pin, PWM
from time import sleep

pwm = PWM(Pin(15))
pwm.freq(1000)

while True:
    pwm.duty_u16(16384)  # 約 25%
    sleep(2)
    pwm.duty_u16(32768)  # 約 50%
    sleep(2)
    pwm.duty_u16(49152)  # 約 75%
    sleep(2)

duty_u16() 的範圍為 0～65535。PWM 輸出仍然是 0 V／3.3 V 的數位脈衝，並非真正的可變直流電壓。
