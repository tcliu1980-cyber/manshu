太陽能板為什麼會發電？

先從「什麼是半導體」開始，理解矽晶格、價帶與導帶，再進入摻雜形成 n 型與 p 型半導體；接著追蹤 p-n 接面形成時載子的擴散、復合、空乏區與內建電場。最後再理解光子如何產生電子—電洞對，並由內建電場分離而形成可利用的電流。

0.1 什麼是半導體？

半導體的導電能力介於導體與絕緣體之間，而且可以透過溫度、光照與摻雜大幅改變。這個「可控制的導電性」正是二極體、電晶體與太陽能電池能工作的基礎。

導體 Conductor

例如銅、鋁。大量電子很容易參與導電，因此電阻通常很小。

價帶與導帶重疊，或存在大量自由載子

半導體 Semiconductor

例如矽 Si、鍺 Ge。常溫下只有部分電子能進入導帶，因此導電性可受外界條件控制。

小但非零的 band gap

絕緣體 Insulator

價帶電子很難跨越很大的能隙，因此一般電場下幾乎沒有可移動載子。

較大的 band gap

以矽 Silicon 為例

矽有四個價電子。在理想晶格中，每一個矽原子會與四個鄰近矽原子形成共價鍵。低溫時，大部分電子被束縛在鍵結中；當獲得足夠熱能或光子能量時，電子可以離開鍵結並進入導帶。

電子離開後，原本的位置留下可以視為正電載子的「電洞 hole」。

電洞不是一顆真正的正粒子。它代表價帶中缺少一個電子的位置；當鄰近電子依序移動填補空位時，看起來就像電洞往相反方向移動。

0.2 什麼是 n 型與 p 型半導體？

純矽稱為本質半導體 intrinsic semiconductor。實際元件通常會加入極少量其他元素，稱為「摻雜 doping」，用來改變自由電子或電洞的數量。

n 型：增加自由電子

在矽中加入五價元素，例如磷 P。磷有五個價電子，其中四個與鄰近矽形成鍵結，剩下的一個電子較容易成為可移動自由電子。

主要載子：電子 e−

這類雜質稱為 donor 施體，因為它容易提供電子。

n 型材料整體仍然是電中性的。「n 型」表示電子是主要載子，不表示整塊材料帶負電。

p 型：增加電洞

在矽中加入三價元素，例如硼 B。硼只有三個價電子，無法完整形成四個鍵，因此留下缺少電子的位置，也就是電洞。

主要載子：電洞 h+

這類雜質稱為 acceptor 受體，因為它容易接受電子。

p 型材料整體也仍然是電中性的。「p 型」表示電洞是主要載子，不表示整塊材料帶正電。

0.3 p-n 接面如何形成？

把 p 型與 n 型半導體接在一起之後，並不是立刻出現一道「牆」。真正發生的是兩側載子濃度不同，因此先出現擴散，再經過復合形成空乏區。

形成過程

  1. 接觸以前：n 側自由電子多，p 側電洞多；兩邊各自近似電中性。
  2. 接觸後開始擴散：電子由高濃度的 n 側往 p 側擴散；電洞則由 p 側往 n 側擴散。
  3. 界面附近發生復合：跨過界面的電子填入電洞，使可移動電子與電洞減少。
  4. 固定離子留下：n 側施體失去電子後留下固定正離子；p 側受體得到電子後留下固定負離子。
  5. 形成空乏區：界面附近幾乎沒有自由多數載子，因此稱為 depletion region。

0.4 p-n 接面為什麼會形成內建電場？

關鍵不是「p 型是正、n 型是負」，而是界面擴散與復合後留下了不能自由移動的固定離子。

空乏區中的固定電荷

在 n 側界面附近，施體原子原本提供的自由電子擴散離開後，留下固定正離子。

在 p 側界面附近，受體原子捕捉電子後，留下固定負離子。

因此在空乏區內出現空間電荷分離：

n 側：固定正電　｜　p 側：固定負電

內建電場方向

電場方向定義為「正測試電荷受力方向」，所以電場由正電指向負電：

E：n 側 → p 側

這個電場會阻止更多多數載子繼續擴散。當漂移與擴散達到平衡後，接面進入熱平衡。

這個內建電場就是太陽能電池能把光生電子與電洞往不同方向分離的重要機制。

1. 光伏效應：光如何產生電子—電洞對？

太陽能電池不是「把光直接變成電壓」。第一步是材料先吸收具有足夠能量的光子，產生可移動的電荷載子。

光子能量

單一光子的能量與頻率成正比、與波長成反比：

E = h f = h c / λ

若光子的能量大於半導體的能隙 Eg，電子可由價帶躍遷到導帶，留下電洞（hole）。這一對稱為電子—電洞對。

能量小於 Eg 的光子通常無法直接產生電子—電洞對；能量遠高於 Eg 的部分能量則多以熱的形式耗散。

2. 光生載子如何被 p-n 接面的內建電場分離？

光照後的載子分離

n 型半導體有較多可移動電子；p 型半導體則有較多電洞。當兩者接觸時，界面附近的多數載子會互相擴散並復合，留下固定離子，形成空乏區 depletion region。

空乏區內因電荷分離形成一個內建電場。當光產生電子—電洞對時，這個內建電場會把電子推向 n 側，把電洞推向 p 側，因此兩端形成電位差。

3. 太陽能板不是固定 6 V：要看 I–V 與 P–V 曲線

標示「6 V / 3 W」不代表它在任何狀況都同時輸出 6 V 與 0.5 A。輸出取決於負載工作點。

Voc

Open-circuit voltage。負載斷開、電流約為 0 時的端電壓。它不是最大功率點。

Isc

Short-circuit current。端電壓接近 0 時的電流。它也不是最大功率點。

MPP

Maximum Power Point。在某一組 Vmp、Imp 下，乘積 V×I 最大，是最值得工作的區域。

P(V) = V × I(V)
所以課堂上除了量「有沒有 6 V」，更好的做法是接一個已知負載或電子負載，量 V 與 I，再計算真正輸出的功率。

5. 入射角：為什麼正對太陽比較有利？

若先只考慮幾何投影，不考慮反射與材料效應，接收到的輻射功率可以用：

P_received ≈ P_normal × cos(θ)

θ 是太陽光方向與太陽能板法線的夾角。

  • θ = 0°：正對太陽，cosθ = 1
  • θ = 60°：只剩幾何上約 50%
  • θ → 90°：投影面積趨近 0
實際輸出不會只由 cosθ 決定，還會受反射、天空散射光、溫度與充電模組工作點影響。

6. 太陽能電池的串聯與並聯

串聯 Series

V_total ≈ V1 + V2 + ...

串聯主要提高電壓，電流能力受最弱的串聯單元限制。局部遮蔽對串聯系統特別重要。

並聯 Parallel

I_total ≈ I1 + I2 + ...

並聯主要提高可提供的電流。各支路電壓應接近一致，實際系統還會考慮反灌電流與保護。

8. 適合在課堂上做的四個實驗

實驗 A｜入射角

固定同一光源與距離，改變板面角度，每 10° 或 15° 量一次工作電壓與電流，再畫 P(θ)。

實驗 B｜局部遮蔽

依序遮住約 0%、25%、50%、75% 面積，觀察電壓、電流與功率哪一個變化最大。

實驗 C｜負載工作點

更換不同電阻或電子負載，量 V、I 並畫出簡化 I–V / P–V 曲線，找出接近最大功率的位置。

實驗 D｜溫度

在安全溫度範圍內比較室溫與受熱後的 Voc，觀察「光很強但板子很熱」不一定讓電壓更高。
