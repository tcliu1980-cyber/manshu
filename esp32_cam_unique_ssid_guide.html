ESP32-CAM 課堂多人連線：設定不同 SSID

讓每位學生用自己的手機連到自己的 ESP32-CAM，避免全班 Wi-Fi 名稱相同造成連錯板子。

一、為什麼要設定不同 SSID？

在課堂上，如果每一片 ESP32-CAM 都使用相同的 Wi-Fi 名稱，例如 ESP32CAM_RC，學生手機會看到很多個同名熱點，容易連到別人的板子。

常見問題：全班都使用相同 SSID 時，學生不容易判斷哪一個熱點是自己的 ESP32-CAM，可能會發生「我推油門，卻控制到別人的馬達」的危險情況。

解法是讓每片 ESP32-CAM 開機後，自動依照自己的晶片編號產生獨一無二的 Wi-Fi 名稱。

ESP32CAM_RC_A83F
ESP32CAM_RC_21B7
ESP32CAM_RC_C902
ESP32CAM_RC_7D10
重點：每一組的 SSID 不同，但連線後的控制網址都一樣是 http://192.168.4.1。

二、學生手機端操作流程

  1. 打開手機 Wi-Fi 設定。
  2. 找到名稱為 ESP32CAM_RC_XXXX 的 Wi-Fi 熱點。
  3. XXXX 是每一片 ESP32-CAM 自己產生的編號，例如 A83F、21B7。
  4. 輸入密碼：12345678。
  5. 連線後，手機可能會顯示「無網際網路連線」，這是正常現象，因為手機是直接連到 ESP32-CAM，不是連到家用網路。
  6. 開啟手機瀏覽器，輸入 http://192.168.4.1。
  7. 進入控制頁面後，即可控制兩個 Servo 與 ESC 油門。
飛機與馬達安全提醒：第一次測試請務必拆掉螺旋槳。確認滑桿、Servo 舵面方向、ESC 油門都正常後，再進入下一階段測試。

三、老師要修改的程式位置

原本的程式通常會把 SSID 寫死成固定名稱：

原本寫法

const char* ssid = "ESP32CAM_RC";
const char* password = "12345678";

請改成下面這樣，讓 ssid 變成可以在程式中自動產生的字串：

修改後寫法

String ssid;
const char* password = "12345678";

四、在 setup() 裡自動產生唯一 SSID

找到原本啟動 Wi-Fi AP 的程式：

原本寫法

WiFi.softAP(ssid, password);

請改成下面這一整段：

建議寫法：自動 SSID + 分散 Wi-Fi 頻道 + 限制一台手機連線

WiFi.mode(WIFI_AP);

// 取得 ESP32 的晶片編號
uint64_t chipid = ESP.getEfuseMac();

// 使用晶片編號最後 4 碼產生 SSID
char ssidName[32];
sprintf(ssidName, "ESP32CAM_RC_%04X", (uint16_t)(chipid & 0xFFFF));

ssid = String(ssidName);

// 讓不同 ESP32-CAM 分散到 Wi-Fi channel 1、6、11
int channels[3] = {1, 6, 11};
int channel = channels[chipid % 3];

// 建立 Wi-Fi AP
// 參數：SSID, 密碼, 頻道, 是否隱藏SSID, 最大連線數
// 最後的 1 表示只允許一台手機連線
WiFi.softAP(ssid.c_str(), password, channel, 0, 1);

Serial.println();
Serial.println("ESP32-CAM RC Controller Started");
Serial.print("Wi-Fi SSID: ");
Serial.println(ssid);
Serial.print("Password: ");
Serial.println(password);
Serial.print("Wi-Fi Channel: ");
Serial.println(channel);
Serial.print("AP IP address: ");
Serial.println(WiFi.softAPIP());
說明：ESP.getEfuseMac() 會讀取每片 ESP32 不同的晶片編號，因此產生出來的 ESP32CAM_RC_XXXX 會不同。

五、完整替換範例

下面是可以直接放進原本 ESP32-CAM 控制程式中的 Wi-Fi AP 設定段落。若你的程式前面已經有 #include <WiFi.h>，就不需要重複加入。

#include <WiFi.h>

String ssid;
const char* password = "12345678";

void setupWiFiAP() {
  WiFi.mode(WIFI_AP);

  uint64_t chipid = ESP.getEfuseMac();

  char ssidName[32];
  sprintf(ssidName, "ESP32CAM_RC_%04X", (uint16_t)(chipid & 0xFFFF));

  ssid = String(ssidName);

  int channels[3] = {1, 6, 11};
  int channel = channels[chipid % 3];

  WiFi.softAP(ssid.c_str(), password, channel, 0, 1);

  Serial.println();
  Serial.println("ESP32-CAM RC Controller Started");
  Serial.print("Wi-Fi SSID: ");
  Serial.println(ssid);
  Serial.print("Password: ");
  Serial.println(password);
  Serial.print("Wi-Fi Channel: ");
  Serial.println(channel);
  Serial.print("AP IP address: ");
  Serial.println(WiFi.softAPIP());
}

然後在原本的 setup() 裡面呼叫：

void setup() {
  Serial.begin(115200);

  // 其他 Servo / ESC 初始化程式...

  setupWiFiAP();

  // 原本的 WebServer 設定...
  server.on("/", handleRoot);
  server.on("/set", handleSet);
  server.begin();
}

六、不同做法比較

做法 範例 優點 缺點
固定 SSID ESP32CAM_RC 程式最簡單 全班同名，容易連錯
手動編號 SSID ESP32CAM_RC_01 學生容易辨識組別 每片板子都要手動改程式
自動晶片編號 SSID ESP32CAM_RC_A83F 每片自動不同，最適合大量上課 學生要記下自己板子的後四碼
課堂建議：大量學生同時操作時，建議使用「自動晶片編號 SSID」；如果每組板子已經貼上組別貼紙，也可以使用「手動編號 SSID」。

七、可選做法：手動指定每組 SSID

如果老師希望每一組有固定名稱，例如第 1 組、第 2 組、第 3 組，可以手動指定：

const char* ssid = "ESP32CAM_RC_GROUP01";
const char* password = "12345678";

不同組別請改成：

ESP32CAM_RC_GROUP01
ESP32CAM_RC_GROUP02
ESP32CAM_RC_GROUP03
ESP32CAM_RC_GROUP04
注意：手動指定 SSID 時，老師或學生燒錄每一片 ESP32-CAM 前都要確認組別號碼，否則仍可能出現重複 SSID。

八、上課檢查清單

  • 每片 ESP32-CAM 開機後，手機 Wi-Fi 清單中應出現不同的 ESP32CAM_RC_XXXX。
  • 每組學生先記下自己板子的 SSID 後四碼。
  • 手機連線後，瀏覽器輸入 http://192.168.4.1。
  • 如果手機顯示「無網際網路連線」，不要切回 4G/5G，仍然要保持連在 ESP32-CAM Wi-Fi。
  • Servo 測試完成前，不要接螺旋槳。
  • ESC 測試時，油門滑桿一開始必須在最低值 1000 µs。

九、講義摘要

在多人上課環境中，ESP32-CAM 必須避免使用相同的 Wi-Fi 熱點名稱。建議使用 ESP.getEfuseMac() 讀取每片 ESP32 的晶片編號，再自動產生 ESP32CAM_RC_XXXX 形式的 SSID。學生只要連到自己板子的 SSID，並開啟 http://192.168.4.1，就能進入控制網頁。
