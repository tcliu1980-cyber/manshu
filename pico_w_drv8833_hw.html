02 / YOUR ACTUAL BOARD

認識您的 DRV8833 模組

原始腳位照片。照片採相同方向閱讀：左側由上到下是 IN4、IN3、GND、VCC、IN2、IN1；右側由上到下是 EEP、OUT1、OUT2、OUT3、OUT4、ULT。

照片標示作用這堂課接到哪裡？
IN1 / IN2第一組 H 橋的兩個輸入Pico W GP14 / GP15
IN3 / IN4第二組 H 橋的兩個輸入Pico W GP16 / GP17
OUT1 / OUT2第一顆馬達的兩端左馬達 A 的兩條線
OUT3 / OUT4第二顆馬達的兩端右馬達 B 的兩條線
VCC馬達驅動電源輸入建議連至穩定 3.7 V 馬達電源正極
GND驅動器電源負極與共地與電池負極、Pico W GND 共地
EEP常見為 nSLEEP 的部分印字若 J2 使其預設啟用，可不另接；否則須依實板確認拉高方式
ULT常見為 nFAULT 的部分印字故障狀態訊號，基礎課可不接
J2與睡眠／啟用配置相關的焊接跳線先確認是否已短接，不要盲目改焊
EEP / ULT 不是另一組馬達輸出。不同批次 HW-627 對 J2 與預設拉高的配置可能不同。如果接線、電源都正確但馬達不動，先停止通電，請教師確認 EEP (nSLEEP) 是否已被設為高電位。ULT 為訊號輸出，不要直接當電源輸入。
03 / WHY DRIVER?

為什麼不能把空心杯馬達直接接在 Pico W 的 GPIO？

Pico W 的 GPIO 是產生控制訊號的腳位，輸出的是 0 V 或約 3.3 V 的數位訊號，不能承擔馬達啟動瞬間可能出現的大電流。馬達又是會產生電磁干擾的負載，直接連接可能讓 Pico W 重開機甚至受損。

🧠 Pico W：決定做什麼

傳送 3.3 V GPIO 邏輯與 PWM，占空比告訴驅動器「開啟多長時間」。

⚡ DRV8833：負責出力

從外部 18650 供電路徑取得馬達電流，靠內部 MOSFET H 橋切換馬達兩端電壓。

最重要的概念：Pico W 的 GPIO 接「IN」，馬達接「OUT」，電池的馬達電源接「VCC/GND」。不要把馬達接在 GP14、GP15 等 GPIO 上。

DRV8833 晶片標示的供電規格約為 2.7～10.8 V，但不同封裝、模組散熱及 PCB 銅箔會限制安全輸出電流。是否適用於您手上的馬達，仍須查看其堵轉電流。參考 TI 官方資料。

04 / H-BRIDGE

DRV8833 的工作原理：什麼是 H 橋？

一顆直流馬達有兩條線。當電流從 A 端流向 B 端，馬達朝一個方向轉；反過來流，便朝另一個方向轉。H 橋就是利用四個電子開關（MOSFET）改變電流方向。

IN1IN2馬達 A 的典型動作說明
00滑行停止（Coast）輸出關閉，馬達靠慣性逐漸停下
10方向 1OUT1 相對 OUT2 施加電壓
01方向 2電流方向反轉
11煞車（Brake）將馬達兩端置於煞車狀態（非斷電滑行）

馬達 B 使用 IN3/IN4，原理完全相同。這裡的方向 1、方向 2 不是絕對的「順時針」「逆時針」，因為馬達安裝方向、線材接法都會影響觀察結果。

PWM 為什麼可以調速？

例如 PWM 頻率 1000 Hz，表示每秒切換約 1000 次。若占空比為 30%，在每個週期中只有約 30% 的時間送出某一驅動狀態。馬達因電感與機械慣性，會呈現不同的平均轉速。占空比不是轉速百分比，也不是精確的電壓穩壓器。

05 / 18650 POWER

外接 18650：同一顆電池如何供電？

3.7 V18650 標稱電壓；也是您馬達的額定電壓
約 4.2 V18650 充滿電時可能有的電壓
1.8～5.5 VPico W VSYS 可接受的輸入範圍

建議方案：一顆 18650，分兩條供電路徑

第一路給 Pico W：電池經電源開關接 Pico W Pin 39 VSYS，負極接 Pin 38 GND。1S 18650 的一般工作電壓處於 Pico W VSYS 允許範圍內。

第二路給馬達：電池經一個合適的 3.7 V 升降壓穩壓器，再接 DRV8833 VCC 與 GND。穩壓器要能承受兩顆馬達的啟動、瞬間電流。先用萬用電表量到接近 3.7 V，才可以接驅動板。

共地：電池負極、Pico W 的 GND、DRV8833 的 GND 與穩壓器的參考地都必須正確共地，否則 DRV8833 不一定看得懂 Pico W 的 3.3 V 控制訊號。

可以省略馬達穩壓器嗎？只有當馬達製造商明確允許 18650 的整個電壓範圍（尤其滿電 4.2 V），而且已確認堵轉電流、散熱與保護條件後，才考慮直接將電池供應 DRV8833 VCC。單靠 PWM 降低占空比，不等於提供恆定的 3.7 V。

不要同時連接usb與 18650電池？

Raspberry pi pico 不是 18650 充電器, 不可以同時連接usb與電池。

⚠️ 本課程基本接線：插 USB 前，先關閉並斷開 18650 供電！
⚠️ 18650 正負極接反、短路或異常發熱，可能造成設備損壞與火災。
⚠️鋰電池安全：若導線、馬達、模組或電池異常發熱，立即停止操作；能安全操作時先關閉開關並斷電。若電池已燙手、冒煙、膨脹或異味，切勿徒手拆線，應遠離並通知教師。

07 / STEP BY STEP

一步一步完成接線

1
先把 18650 從電池座取下／確保開關關閉把螺旋槳拆下，讓馬達軸不會碰到手、線材或桌面。
2
確認電池的正負極與規格利用萬用電表量測電池端電壓，不要只依線色判斷。使用您已確認內建保護的 1S 18650。
3
先完成共地將 Pico W Pin 38 接到共地；將 DRV8833 GND、穩壓器 GND 依模組要求接到同一電池負極參考點。
4
先測 3.7 V 穩壓輸出，之後才接 DRV8833未負載時先量好輸出與極性，並確認模組可承受馬達啟動電流。若無合適穩壓器，先停在不接馬達的軟體練習階段。
5
把兩顆馬達接到 OUT1/2 和 OUT3/4馬達 A 接 OUT1、OUT2；馬達 B 接 OUT3、OUT4。兩根線互換會使該顆馬達的轉向相反。
6
接四條控制線Pico W GP14 → IN1、GP15 → IN2、GP16 → IN3、GP17 → IN4，且確認 J2 / EEP 的睡眠設定。
7
接電源正極電池正極經開關分別通往 Pico Pin 39 VSYS 及穩壓器輸入；穩壓器 +3.7 V 輸出通往 DRV8833 VCC。
8
教師用萬用電表復核檢查無正負極顛倒、無短路、VCC/VSYS 對地電壓合理，再進行通電。第一次測試請限短時間、低占空比。

09 / PWM SPEED

第一個馬達控制實驗：從停止到慢速

我們先只操作 OUT1/OUT2 的馬達 A，讓學生理解 Pin()、PWM()、freq() 與 duty_u16()。

02｜單顆馬達：逐步提高占空比
from machine import Pin, PWM
from time import sleep

# 與網頁接線表一致：IN1 -> GP14，IN2 -> GP15
in1 = PWM(Pin(14))
in2 = PWM(Pin(15))
in1.freq(1000)
in2.freq(1000)

# 上電後先停止，避免馬達意外啟動
in1.duty_u16(0)
in2.duty_u16(0)

def motor_a(speed):
    # speed 範圍 0~100：0=停止，100=最大占空比
    speed = max(0, min(100, speed))
    in2.duty_u16(0)
    in1.duty_u16(int(speed * 65535 / 100))

try:
    for speed in (0, 20, 35, 50, 0):
        print("馬達 A 占空比:", speed, "%")
        motor_a(speed)
        sleep(2)
finally:
    motor_a(0)
    print("測試結束，馬達停止")
語法說明
PWM(Pin(14))將 GP14 設為可輸出 PWM 的腳位。
freq(1000)PWM 每秒執行約 1000 個週期。
duty_u16(0)0／65535：占空比 0%，將該輸入保持為低。
duty_u16(32768)約 50% 占空比；不是保證 50% 的轉速。
try: ... finally:正常結束或 Ctrl+C 中斷時，執行清理程式讓馬達停止。
安全控制：示範占空比不應視為特定馬達的安全保證。先用低占空比、短時間、無螺旋槳測試；若發熱或不轉卻持續通電，應立即停機。尚未確認允許 4.2 V 的馬達不可使用滿電電池直接試全速。

第二個實驗：改變馬達旋轉方向

03｜單顆馬達：正轉、停止、反轉
from machine import Pin, PWM
from time import sleep

in1 = PWM(Pin(14), freq=1000, duty_u16=0)
in2 = PWM(Pin(15), freq=1000, duty_u16=0)

def motor_a(speed):
    # -100 ~ +100；正負號代表兩個方向
    speed = max(-100, min(100, speed))
    duty = int(abs(speed) * 65535 / 100)
    # 先關閉兩端，避免切換方向時瞬間衝擊
    in1.duty_u16(0)
    in2.duty_u16(0)
    sleep(0.1)
    if speed > 0:
        in1.duty_u16(duty)
    elif speed < 0:
        in2.duty_u16(duty)

try:
    motor_a(30)
    sleep(2)
    motor_a(0)
    sleep(1)
    motor_a(-30)
    sleep(2)
finally:
    motor_a(0)
10 / TWO MOTORS

兩顆空心杯馬達：風扇船差速轉向

假設兩顆馬達正向都能使風扇船向前推進，當左馬達較慢、右馬達較快時，船通常會往左轉；反之往右轉。實際轉向仍會受到螺旋槳旋向、軸安裝方向、船體阻力等影響，必須實測。

04｜雙馬達差速控制：風扇船基礎程式
from machine import Pin, PWM
from time import sleep

# 馬達 A：IN1=GP14，IN2=GP15
# 馬達 B：IN3=GP16，IN4=GP17
pins = [14, 15, 16, 17]
pwm = [PWM(Pin(p), freq=1000, duty_u16=0) for p in pins]

def set_motor(i, speed):
    # i = 0 表示馬達 A；i = 1 表示馬達 B
    # speed 可為 -100 ~ +100
    speed = max(-100, min(100, int(speed)))
    a, b = pwm[i * 2], pwm[i * 2 + 1]
    a.duty_u16(0)
    b.duty_u16(0)
    duty = int(abs(speed) * 65535 / 100)
    if speed > 0:
        a.duty_u16(duty)
    elif speed < 0:
        b.duty_u16(duty)

def drive(left, right):
    set_motor(0, left)
    set_motor(1, right)
    print("左:", left, "右:", right)

def stop():
    drive(0, 0)

try:
    # 先架空船體／拆下螺旋槳做桌上測試
    drive(30, 30)   # 直行
    sleep(2)
    stop()
    sleep(1)
    drive(15, 35)   # 左側較慢：偏左轉
    sleep(2)
    stop()
    sleep(1)
    drive(35, 15)   # 右側較慢：偏右轉
    sleep(2)
finally:
    stop()
    print("全部停止")
左馬達右馬達預期用途
30%30%嘗試直線前進
15%35%嘗試向左轉
35%15%嘗試向右轉
0%0%滑行停止

延伸：讓學生自己輸入數字

from machine import Pin, PWM

in1 = PWM(Pin(14), freq=1000, duty_u16=0)
in2 = PWM(Pin(15), freq=1000, duty_u16=0)

try:
    while True:
        text = input("輸入占空比 0~50，q 結束：").strip()
        if text.lower() == "q":
            break
        try:
            speed = int(text)
            if not 0 <= speed <= 50:
                print("請輸入 0 到 50")
                continue
            in2.duty_u16(0)
            in1.duty_u16(int(speed * 65535 / 100))
            print("占空比已設為", speed, "%")

            print("請輸入數字或 q")
finally:
    in1.duty_u16(0)
    in2.duty_u16(0)
    print("馬達停止")

13 / DEBUG

遇到問題時怎麼辦？

程式正常執行，馬達卻完全不轉

先斷電：確認 OUT1/2 有接馬達、DRV8833 的 VCC/GND 有正常供電、GPIO 接線對應正確；再檢查 HW-627 的 J2 與 EEP（睡眠／啟用）狀態。部分模組必須使 nSLEEP 為高，才會驅動輸出。

LED 測試沒問題，一開馬達 Pico W 就重開機

常見原因是電池、接線或穩壓器承受不了馬達啟動電流，造成瞬間電壓下降。請量測電池與 VSYS、檢查接點；必要時分開規劃供電去耦與佈線，不要改用 Pico W 3V3 直接餵馬達。

左右馬達轉向不同

先斷電。可將其中一顆馬達的兩條輸出線對調，或在程式中針對該馬達改變正負速度的對應，不要帶電拔插馬達導線。

PWM 設為 20%，但馬達不轉；提高後突然啟動

馬達啟動需克服靜摩擦與負載扭矩，低占空比可能不足以啟動。這是正常現象之一，也說明占空比和真實 RPM 並非線性關係。不要讓馬達長時間停滯通電。

輸入 0% 仍然有轉動？

先確認程式有同時將兩個方向輸入設為 0，並確定沒有其他程式（如 main.py）在改寫 GPIO；再檢查 wiring 與模組是否已損壞。

DRV8833 很熱

立即停機並安全斷電。檢查短路、馬達是否堵轉、啟動電流是否超過該 HW-627 板與晶片封裝能承受的連續能力。TI 規格會因封裝而不同，不要把「峰值 2 A」當成可長時間連續輸出 2 A。
