已知馬達＋螺旋槳推力，如何估算 RC 飛機速度與升力？

用推力、機翼面積、機重與阻力模型，估算「能不能飛起來」、「失速速度」、「最大水平飛行速度」與「指定速度下的升力」。

1. 先講結論：可以估算，但不能只靠推力

如果已知馬達搭配螺旋槳的推力，例如測得 350 g 推力，我們可以粗略估算飛機的水平速度與升力。不過要注意，單靠推力不能直接算出升力，因為升力主要由下式決定：

L = 1/2 × ρ × V² × S × CL 升力需要知道速度 V、機翼面積 S、升力係數 CL

馬達推力比較適合用來估算「飛機能克服多少阻力」，也就是：

T ≈ D 水平定速飛行時，推力約等於阻力
重要：一般網路上標示的推力多半是「靜態推力」，也就是飛機不動時測到的推力。飛機往前飛時，螺旋槳推力通常會下降，所以本網頁只適合做課堂設計估算，不等於精密飛行性能分析。

2. 本頁使用的簡化物理模型

水平飛行時，飛機需要同時滿足兩個條件：

方向 近似平衡條件 意義
垂直方向 L ≈ W 升力約等於重量，飛機才不會掉下去
水平方向 T ≈ D 推力約等於阻力，飛機才能維持定速

阻力估算

本頁用一個簡化阻力模型：

D = 1/2 ρ V² S CD0 + k W² / (1/2 ρ V² S) 總阻力 = 零升阻力 + 誘導阻力

其中：

參數 意義 教學建議值
CD0 零升阻力係數，代表機身、機翼表面、線材、起落架等造成的阻力 KT 板簡易飛機可先用 0.06 ~ 0.12
e Oswald efficiency，有限翼效率 簡易矩形翼可先用 0.65 ~ 0.80
AR 展弦比，AR = b²/S 90 cm × 18.6 cm 約為 4.84
k 誘導阻力參數 k = 1/(π e AR)

4. 推力與阻力曲線

藍線是可用推力，橘線是維持水平飛行所需阻力。兩條線交會處約為最大水平飛行速度。紅色虛線是失速速度，低於此速度即使推力足夠，也可能因升力不足而掉高度。

5. 如何判斷這組馬達與螺旋槳是否足夠？

  1. 先看推重比 T/W。初學 KT 板高翼機建議至少約 0.5 以上，0.7 以上會比較有餘裕。
  2. 看失速速度 Vstall。如果失速速度太高，學生手拋會很困難。
  3. 看最大水平速度是否明顯大於失速速度。若 Vmax 只比 Vstall 高一點點，飛機會非常難飛。
  4. 看指定速度所需 CL 是否小於 CL,max。若需要的 CL 超過 CL,max，該速度下升力不足。
  5. 確認飛機總重。相同推力下，減重通常比換大螺旋槳更有效且更安全。
對 90 cm 翼展、18.6 cm 翼弦的課堂高翼機：若總重能壓在 500 g ~ 700 g，且靜態推力約 350 g ~ 600 g，通常比較容易進入可測試範圍。若總重接近 1 kg，則需要更高推力、更大機翼或更快速度。

6. 教學提醒：靜態推力不是飛行速度

常見錯誤是把「450 g 推力」直接想成「可以吊起 450 g 飛機」。這只對垂直懸停概念有部分意義，但一般固定翼不是靠推力把飛機往上拉，而是靠機翼前進產生升力。

概念 代表意義 固定翼設計時怎麼用
靜態推力 飛機不動時，馬達與槳可推多少力 判斷加速能力與爬升能力
飛行速度 飛機相對空氣的速度 決定升力大小
升力 機翼向上的力 要至少接近飛機重量才能平飛
阻力 飛機前進時受到的空氣阻力 決定馬達推力能讓飛機飛多快
課堂實測建議：先拆槳測 Servo，再固定機身測油門，再用彈簧秤或電子秤測靜態推力，最後才進行短距離滑跑或手拋測試。

7. 核心 JavaScript 公式

若要把計算功能嵌入其他頁面，最核心的計算如下：

const g = 9.81; const rho = 1.225; const massKg = 0.65; const staticThrustN = 0.45 * g; const span = 0.90; const chord = 0.186; const S = span * chord; const AR = span * span / S; const e = 0.70; const CD0 = 0.08; const k = 1 / (Math.PI * e * AR); const W = massKg * g; // 失速速度 const CLmax = 1.10; const Vstall = Math.sqrt(2 * W / (rho * S * CLmax)); // 水平飛行阻力：L = W function dragLevelFlight(V) { const q = 0.5 * rho * V * V; return q * S * CD0 + k * W * W / (q * S); } // 最大水平速度約在 T_available(V) = D(V) 的交點
