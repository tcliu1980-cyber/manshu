單元 03｜Pico W × DRV8833 雙馬達控制

國高中生實作課程｜3.7 V 有刷空心杯馬達 × 單顆 18650 電池

一、學習目標

學會認識 H 橋、分辨邏輯訊號與馬達電源、用 Thonny 撰寫 MicroPython 程式，控制兩顆馬達的啟停、轉向及 PWM 速度。

本課程使用的是有刷空心杯馬達，不是三相無刷馬達。DRV8833 是雙 H 橋驅動器，適合有刷直流馬達。

二、電池與供電

元件規格與用途
18650 電池單顆 1S；標稱約 3.7 V，充滿約 4.2 V
馬達兩顆額定 3.7 V 的有刷空心杯馬達
DRV8833雙 H 橋，馬達供電 VM 依模組資料確認
Pico W3.3 V GPIO；建議以適當穩壓電源供應 VSYS

安全：使用具過充、過放及過流保護的 1S 電池組與合適充電器；不得短路、反接或直接把電池接到 GPIO。18650 充滿的 4.2 V 可能高於馬達容許電壓，須先查明規格；必要時加入適合馬達電流的穩壓模組。Pico W 與 DRV8833 控制訊號必須共地。請由教師確認馬達堵轉電流與驅動器散熱能力。

部分 DRV8833 模組具有 nSLEEP、SLP 或 STBY 腳位，必須依模組說明拉至啟用狀態；不同廠商板子的腳位排列可能不同。電池供電應經過保護與開關，Pico W 的供電則須符合 VSYS 規格。

四、第一個馬達控制程式

在 Thonny 選擇 MicroPython (Raspberry Pi Pico)，先用 USB 連接 Pico W，確認馬達固定牢靠、螺旋槳暫時拆除，再執行：

from machine import Pin
from time import sleep

a1 = Pin(14, Pin.OUT)
a2 = Pin(15, Pin.OUT)

# 正轉 1 秒
a1.value(1)
a2.value(0)
sleep(1)

# 停止（滑行）
a1.value(0)
a2.value(0)

Pin(14, Pin.OUT)：把 GP14 設為輸出腳。value(1) 代表高電位，value(0) 代表低電位。兩個輸入一高一低時，馬達依接線方向轉動；兩個輸入皆低時為滑行停止。

五、PWM 調速與雙馬達

PWM 會快速切換高低電位，duty_u16(32768) 約為 50% 占空比。以下程式示範前進、左轉、右轉、停止；僅在確認馬達及電源規格後實際測試。

from machine import Pin, PWM
from time import sleep

LA = PWM(Pin(14))
LB = Pin(15, Pin.OUT)
RA = PWM(Pin(16))
RB = Pin(17, Pin.OUT)

LA.freq(1000)
RA.freq(1000)
LB.value(0)
RB.value(0)

def drive(left, right):
    # 此入門範例僅示範單方向、0~100% 速度
    left = max(0, min(100, left))
    right = max(0, min(100, right))
    LA.duty_u16(int(left * 65535 / 100))
    RA.duty_u16(int(right * 65535 / 100))

try:
    drive(40, 40)  # 前進
    sleep(2)
    drive(20, 60)  # 左轉
    sleep(2)
    drive(60, 20)  # 右轉
    sleep(2)
finally:
    drive(0, 0)   # 即使中斷也嘗試停止

差速轉向：左馬達比右馬達慢，船通常向左轉；右馬達較慢則向右轉。實際方向也與馬達安裝方向、螺旋槳及船體有關。
